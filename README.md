## 拿到 IP 之后怎么测

**ping 看延迟基准，mtr / tracert 看回程和丢包。** 两步就够了，别一上来跑一堆脚本。

第一步，看延迟大概在什么量级：


ping 128.241.251.254


第二步，看数据包走哪条路、在哪一跳开始丢：


mtr -rwzc 30 128.241.251.254


Windows 没有 mtr，用 `tracert 128.241.251.254`，或者装个 WinMTR 跑几分钟。

**延迟参考值**（第三方测评数据，测试时间 2024 年，只能当基准，实际以你本地网络为准）：

- 香港到国内主要城市：约 30–45ms
- 洛杉矶：约 170ms
- 伦敦：约 179ms
- 法兰克福：约 208ms

**回程看什么**：香港节点已知的回程走向是电信走 CN2 / CTGNet（AS4809，路由里出现 `59.43.x.x`），联通走 CUG（AS10099）接 AS4837 或 AS9929，移动走 CMI（AS58453）接 AS9808。洛杉矶 Premium 的三网回程是 CMIN2。你在 mtr 结果里看到这些 AS 号和网段，说明走的是优化线路；如果一路都是普通骨干网 IP 绕来绕去，那就是没走优化。

同一个 IP，电信、联通、移动三家测出来的结果可能差很多。尤其是 Premium 档，务必在你自己的宽带环境里测，别拿别人家的截图当结论。

## 三档差价极小，选错线路比选错配置更亏

这是很多人没注意到的一点：**洛杉矶三个档位的价格完全一样**，1C1G 都是 $4，2C2G 都是 $5.60。台湾和马尼拉也是这个规律，1C1G $5、2C2G $17，Premium 和 Global 同价。

差的是带宽和回程。洛杉矶 Premium 1C1G 给 20M，Standard 给 50M，Global 给 100M；2C2G 分别是 30M、100M、200M。也就是说，同样的钱，你选了 Global 就拿到五倍带宽，代价是回国线路不做优化。

所以真正该纠结的不是“$4 还是 $5.6”，而是“我这台机器主要是谁在访问”。给国内用户用却买了 Global，省下的那点钱全赔在延迟和丢包上；反过来，用户都在美国，买 Premium 就是白花钱。

另一个明显的价格落差在 2C2G：洛杉矶 $5.60，台湾和马尼拉 $17，差三倍。如果你的业务不需要落地在台湾或菲律宾本地，洛杉矶 2C2G 是这张表里性价比最高的一档。

香港是另一种情况。它只有 10M 和 20M 两档小带宽，$5 起，胜在三网直连、延迟低，适合建站和轻量业务，不适合跑大流量。已经公开的香港测评里，10M 带宽的国际测速上下行基本跑满，说明带宽标注是实的。
